## Website

An English / Thai portfolio featuring selected projects, experience,
education, and contact information. The orange and black design includes
an original particle orbit, soft lighting, and floating dust.

The site is static HTML, CSS, and JavaScript. No installation or build step
is needed. GitHub Pages publishes the `main` branch from the repository root.
Changes pushed to `main` update the live site automatically.

## Edit the site

- `index.html`: page structure and English content.
- `style.css`: responsive visual design.
- `app.js`: Thai translations, project details, and interactions.
- `assets/`: portrait, CV, fonts, and project illustrations.
- `robots.txt` and `sitemap.xml`: search-engine discovery.

For local preview: `python -m http.server 4173`, then open
`http://127.0.0.1:4173`.

## Assets

The portrait and CV were supplied by Pham Buasawan. The portrait background
was removed using ImageGen. The energy project concept image comes from the
SPCSSim repository; it is identified as concept artwork. Other project
illustrations and particle graphics were created for this portfolio.
The locally served Space Grotesk, IBM Plex Mono, and Noto Sans Thai fonts
include their licenses in `assets/`.
